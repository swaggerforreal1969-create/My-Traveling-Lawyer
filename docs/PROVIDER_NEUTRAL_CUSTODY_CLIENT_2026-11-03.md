# Provider-neutral custody client — offline separate-process acceptance

**Classification: experimental acceptance only. No real independent provider has been connected.** New `src/provider_neutral_custody_client.py` contains no URL, HTTP adapter, credentials, key or automatic service activation.

The app must supply an `AuthenticatedCustodyTransport(request=..., transport_authenticated=True)`. This flag asserts operator-provided authenticated transport and is **not verification of TLS, an external operator, or independently administered custody**. A real adapter must be independently audited for transport security, remote credential lifecycle and replay safety before use.

`CustodyClient(transport=..., pinned=..., verify_signature=...)` demands an independently retained predecessor pin and externally supplied signature verifier. `admit_once(..., explicit_authorization=True)` makes **exactly one** request for a nonce and reservation and returns only an untrusted acknowledgment. `reconcile_read_only(...)` reauthenticates the reader and checks the signed head with a matching committed event via the existing `CheckpointReadbackBoundary`. Missing, stale, forged, revoked, mismatched, or unreachable readback fails closed. `CustodyObservation.independently_custodied` remains `False`, always. Neither call clears local attorney pending writes, replays an uncertain request, advances the external pin, or activates production.

`tests/test_provider_neutral_custody_client.py` runs the existing SQLite provider in a **separate local process** behind a controlled Python Pipe fixture (NOT production-safe deserialization or a real network service). Synthetic credentials/signatures and caller-held pin drive adversarial acceptance: wrong credentials, explicit authorization, competing operators, post-commit lost acknowledgment, signer revocation, tampered provider history, forged trust pin, unavailable transport and malformed requests. The fixture is not independently trusted. Real-service acceptance additionally requires authenticated remote transport, a separately administered durable authority, publicly verified signatures and operator-held immutable pins, actual crash/rollback and revocation experiments, genuine key custody, and named external security review.

Ten frozen originals remain restricted. The strict 42-file source/hash gate is not bypassed. No external egress, provisioning, new permissions, deployment or merge is authorized.
